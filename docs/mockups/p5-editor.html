4 · Settings → Library (admin) — hand-edits, rescan & backups

The exported YAML stays hand-editable. The server reconciles on boot and on demand: a cleanly edited file wins; a file that conflicts with an in-app edit loses to the database but is kept next to it as .conflict-<timestamp>.yaml; a malformed file is skipped with a warning. Backups bundle the YAML library and a database snapshot.
