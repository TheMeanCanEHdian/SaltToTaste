1 · Settings → Tags (admin only)

Tags come from recipes — this tab styles how each tag's chip renders everywhere (grid tiles, detail pages, search). A style is a Lucide icon + text color + background, each optional; unstyled tags keep the default rose chip. Clicking a recipe count runs a tag: search. Today the ATK import carries a single real tag (dessert · 214); the other rows illustrate household tags you'll add once editing lands in P5.
